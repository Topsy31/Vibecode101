5. Data Model Changes

How the activity data structure would change.

Current Structure

{
  id: 123,
  name: "Development",
  duration: 10,
  dependency: "FS"  // single type
}

Only supports one implicit predecessor (previous row)

Proposed Structure

{
  id: 123,
  name: "Development",
  duration: 10,
  dependencies: [
    {
      predecessorId: 101,
      type: "FS",
      lag: 0
    },
    {
      predecessorId: 102,
      type: "FS",
      lag: 0
    }
  ]
}

Supports multiple explicit predecessors with types and lag

6. Migration & Backwards Compatibility

Existing saved projects use the old format. On load, migrate automatically:

// Migration function
function migrateActivity(activity, index, allActivities) {
  if (activity.dependencies) {
    return activity; // Already new format
  }

  // Convert old format to new
  return {
    ...activity,
    dependencies: index === 0
      ? []  // First task has no dependencies
      : [{
          predecessorId: allActivities[index - 1].id,
          type: activity.dependency || 'FS',
          lag: 0
        }]
  };
}
