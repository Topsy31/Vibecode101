# Hierarchy Editor

## Purpose

Visualise organisational structures (org charts) and Work Breakdown Structures (WBS) in Tree View or Organogram modes.

**Best For:** Org charts, project decomposition (WBS), reporting hierarchies.

---

## Quick Start

1. **Choose Mode** — Tree View (indented list) or Organogram (boxes & lines)
2. **Add Root Node** — Top-level item (e.g., "CEO" or "Project")
3. **Add Child Nodes** — Sub-items under root
4. **View Structure** — Switch between modes

---

## Features

### Tree View

**Format:** Indented list with expand/collapse

**Adding Nodes:** Click "+

" on parent → Enter name → Save

**Editing:** Click node → Edit name, colour

**Deleting:** Click "Delete" (removes node and all children)

### Organogram Mode

**Format:** Visual boxes connected by lines

**Layout:** Auto-arranges hierarchy (top-down)

**Navigation:** Zoom in/out, pan

### WBS Use Case

**Example:**
- Project (root)
  - Phase 1 (child)
    - Task 1.1 (grandchild)
    - Task 1.2
  - Phase 2

---

## Integration with PMPlan

**Pulls:** Org chart structure, WBS decomposition

**Sections Fed:** Team & Organisation, WBS

---

## Tips

- **Flat Hierarchies:** Max 3-4 levels (readability)
- **Colour Coding:** Use colours for departments or phases
- **Export:** Save as JSON for backup
