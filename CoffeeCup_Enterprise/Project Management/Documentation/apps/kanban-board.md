# Kanban Board

## Purpose

The Kanban Board is a visual task management tool for tracking work items through workflow stages. It uses drag-and-drop cards across customisable columns, with built-in analytics for workload balancing and velocity tracking.

**Best For:** Agile teams, personal task management, sprint planning, workflow visualisation.

---

## Quick Start

1. **Add Columns** — Default: To Do, In Progress, Done (customisable)
2. **Create Cards** — Click "+ Add Card" in any column
3. **Drag Cards** — Move between columns as work progresses
4. **View Analytics** — Switch to Analysis tab for KPIs

---

## Features

### Columns

**Default Columns:** To Do, In Progress, Done

**Adding Columns:**
- Settings → Add Column → Enter name, choose colour

**Editing Columns:**
- Settings → Edit column name, colour, WIP limit

**WIP Limits:**
- Set maximum cards per column (e.g., In Progress: 3 cards max)
- Visual warning when limit exceeded

### Cards

**Fields:** Title, Description, Assignee, Priority (Low/Medium/High), Due Date

**Creating Cards:** Click "+ Add Card" → Fill form → Save

**Editing Cards:** Click card → Edit modal → Modify fields

**Drag-and-Drop:** Click and drag cards between columns

### Analysis Tab

**Metrics:**
- Total cards, completion rate
- Cards per column (distribution)
- Average cycle time
- Workload by assignee

**Charts:** Bar chart (cards per column), pie chart (completion %)

---

## Integration with PMPlan

**Pulls:** Task progress stats, completion rates

**Use Case:** Dashboard KPIs in PMPlan overview

---

## Tips

- **Limit WIP:** Keep "In Progress" to 3-5 cards max (focus)
- **Archive Done:** Move completed cards to archive weekly
- **Use Priorities:** High = urgent, Medium = normal, Low = backlog

---

## Keyboard Shortcuts

- **Enter:** Save card
- **Esc:** Close card modal
