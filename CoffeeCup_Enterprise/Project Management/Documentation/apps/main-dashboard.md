# Main Dashboard

## Purpose

Navigation hub for the entire CoffeeCup suite—grid of application tiles for quick access.

**Best For:** Starting point, discovering available tools, launching applications.

---

## Quick Start

1. Open `Main/index.html` in browser
2. Click any tile to launch that application
3. Theme selection applies across all apps

---

## Features

### Application Grid

**Layout:** Grid of tiles (cards) with:
- Application icon (gradient background)
- Application name
- Short description
- Launch button

**Tiles:**
- Gantt Chart
- Kanban Board
- Risk Register
- Hierarchy Editor
- Delphi Tool
- RACI Matrix
- PMPlan
- Cost Tracker
- Main Dashboard (self-reference)

**Future:** Tiles for Stakeholder Map, Change & Issue Register, EVM Dashboard, Quality Register (as they're built).

---

### Theme Selector

**Location:** Header (top-right)

**Themes:**
- Blueprint (default)
- Fun & Vibrant
- Dark Mode
- Traditional

**Persistence:** Theme selection saves to localStorage and applies across all CoffeeCup apps.

---

### Navigation

**Opening Apps:**
- Click tile → Opens app in same tab (replaces Main Dashboard)
- Use browser back button to return to Main Dashboard

**Bookmarking:**
- Bookmark Main Dashboard (`Main/index.html`) for quick access
- Or bookmark individual apps directly (e.g., `Gantt/index.html`)

---

## Tips

**First-Time Users:** Start with Main Dashboard to explore available tools.

**Power Users:** Bookmark frequently-used apps directly (skip Main Dashboard).

**Theme Selection:** Change theme once in Main Dashboard—applies to all apps automatically.
